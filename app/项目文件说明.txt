1. test_image.py ⭐⭐⭐
   命令行图片分析工具
   用法: python test_image.py photo.jpg
   特点: 快速测试、支持自定义提示词、多角度分析模式

2. image_analyzer.py ⭐⭐⭐
   Python SDK - 13种分析方法
   用法: from image_analyzer import ImageAnalyzer
   特点: 功能强大、可集成到项目、支持批量处理

3. web_image_upload.html ⭐⭐⭐
   网页界面 - 最友好
   用法: 直接在浏览器中打开
   特点: 拖拽上传、实时预览、无需编程

4. demo_image_analysis.py ⭐⭐
   完整演示脚本
   用法: python demo_image_analysis.py photo.jpg [--full]
   特点: 展示所有分析功能（快速/完整两种模式）

🎯 核心功能 - ImageAnalyzer 的 13 种方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1.  analyze()              - 基础分析
2.  detect_objects()       - 物体检测
3.  describe_scene()       - 场景描述
4.  extract_text()         - OCR 文字提取
5.  analyze_emotion()      - 情感分析
6.  identify_colors()      - 颜色识别
7.  analyze_composition()  - 构图分析
8.  answer_question()      - 图片问答
9.  generate_caption()     - 生成标题（4种风格）
10. check_quality()        - 质量评估
11. detect_faces()         - 人脸检测
12. categorize()           - 图片分类
13. batch_analyze()        - 批量分析
