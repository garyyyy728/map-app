### 方式 2️⃣：命令行工具（推荐测试）

**特点**：
- ✅ 快速测试

- ✅ 详细输出

---

### 方式 3️⃣：Python 代码（推荐开发）

**最强大！适合集成到项目！**

```python
from image_analyzer import ImageAnalyzer

# 创建分析器
analyzer = ImageAnalyzer()

# 基础分析
result = analyzer.analyze("photo.jpg")
print(result)

# 物体检测
objects = analyzer.detect_objects("photo.jpg")
print(objects)

# OCR 文字提取
text = analyzer.extract_text("document.png")
print(text)

# 批量处理
images = ["img1.jpg", "img2.jpg", "img3.jpg"]
results = analyzer.batch_analyze(images)
```

**特点**：
- ✅ 13 种分析方法
- ✅ 批量处理
- ✅ 灵活集成
- ✅ 完整错误处理

## 🎨 ImageAnalyzer 的 13 种方法

| 方法 | 用途 | 示例 |
|------|------|------|
| `analyze()` | 基础分析 | 描述图片内容 |
| `detect_objects()` | 物体检测 | 识别所有物体 |
| `describe_scene()` | 场景描述 | 详细描述场景 |
| `extract_text()` | OCR 文字提取 | 提取文档文字 |
| `analyze_emotion()` | 情感分析 | 识别人物情绪 |
| `identify_colors()` | 颜色识别 | 分析主色调 |
| `analyze_composition()` | 构图分析 | 评估摄影构图 |
| `answer_question()` | 图片问答 | 回答关于图片的问题 |
| `generate_caption()` | 生成标题 | 生成图片标题 |
| `check_quality()` | 质量评估 | 评估图片质量 |
| `detect_faces()` | 人脸检测 | 检测人脸特征 |
| `categorize()` | 图片分类 | 自动分类图片 |
| `batch_analyze()` | 批量分析 | 批量处理图片 |

## 💡 常见应用场景

### 📝 文字识别（OCR）
```python
# 提取发票文字
text = analyzer.extract_text("invoice.jpg")

# 提取名片信息
info = analyzer.analyze("card.jpg", "提取姓名、电话、邮箱")
```

### 🛍️ 电商应用
```python
# 商品识别
product = analyzer.analyze("product.jpg", "识别商品品牌和型号")

# 生成商品标题
title = analyzer.generate_caption("product.jpg", style="专业")
```

### 📱 社交媒体
```python
# 生成创意标题
caption = analyzer.generate_caption("selfie.jpg", style="创意")

# 场景识别
scene = analyzer.describe_scene("travel.jpg")
```

### 🏠 房地产
```python
# 识别房间
room = analyzer.analyze("room.jpg", "这是什么房间？")

# 装修风格
style = analyzer.analyze("room.jpg", "描述装修风格")
```

## ❓ 常见问题

### Q: 无法连接到服务器？
**A**: 确保后端服务已启动：`python main.py`

### Q: 显示地理位置限制？
**A**: 需要配置代理，详见 [PROXY_SETUP.md](PROXY_SETUP.md)

### Q: 依赖包缺失？
**A**: 安装依赖：`pip install -r requirements.txt`

### Q: 图片分析失败？
**A**: 检查：
1. 服务器是否运行
2. 代理是否配置（如需要）
3. 图片文件是否存在
4. 图片格式是否支持
