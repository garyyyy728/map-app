## 🔧 如果端口号不对

如果您的代理端口不是 7890，需要修改 `.env` 文件：

### 常见端口号

| 代理工具 | 默认端口 |
|---------|---------|
| Clash | 7890 |
| V2rayN | 10809 |
| Shadowsocks | 1080 |

### 修改步骤

1. 打开 `.env` 文件
2. 修改这两行的端口号：
```env
HTTP_PROXY=http://127.0.0.1:您的端口号
HTTPS_PROXY=http://127.0.0.1:您的端口号
```
3. 保存文件
4. 重启服务

### 自动检测端口

运行这个脚本自动检测可用端口：
```bash
python check_proxy.py
```

## 🎯 配置成功后可以做什么

一旦配置成功，您就可以使用三种方式进行图片分析：

### 1. 网页界面（最友好）
```
打开 web_image_upload.html
```
- 拖拽上传图片
- 选择快捷提示词
- 实时查看结果

### 2. 命令行工具（最快速）
```bash
# 基础分析
python test_image.py photo.jpg

# 自定义提示
python test_image.py photo.jpg "这张图片里有什么？"

# 多角度分析
python test_image.py photo.jpg --multi
```

### 3. Python SDK（最强大）
```python
from image_analyzer import ImageAnalyzer

analyzer = ImageAnalyzer()

# 基础分析
result = analyzer.analyze("photo.jpg")

# OCR 文字提取
text = analyzer.extract_text("document.png")

# 批量处理
images = ["img1.jpg", "img2.jpg", "img3.jpg"]
results = analyzer.batch_analyze(images)
```
