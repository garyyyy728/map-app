# ⚡ 快速切换节点 - 3 步搞定

## 🎯 目标：让 Gemini API 可以访问

---

## Clash for Windows 用户

### 第 1 步：打开全局模式
1. 双击托盘的 Clash 图标
2. 点击 **"Proxies"** 标签页
3. 顶部模式切换为 **"Global"**（不是 Rule 或 Direct）

### 第 2 步：选择美国节点
1. 在节点列表中找到带有这些标识的节点：
   - 🇺🇸 US / United States / 美国
   - 🇯🇵 JP / Japan / 日本
   - 🇸🇬 SG / Singapore / 新加坡
2. 点击选中该节点

### 第 3 步：测试
```powershell
python test_api_endpoint.py
```

**看到 "状态码: 200" 就成功了！**

如果还是 400：换另一个节点，重复第 2-3 步

---

## V2rayN 用户

### 第 1 步：设置全局模式
1. 右键托盘的 V2rayN 图标
2. **系统代理** → 勾选 **"自动配置系统代理"**
3. **Http代理** → 选择 **"全局模式"**

### 第 2 步：选择节点
1. 双击托盘图标打开主窗口
2. 在服务器列表中找到美国/日本/新加坡节点
3. 双击该节点（或右键 → 设为活动服务器）

### 第 3 步：测试
```powershell
python test_api_endpoint.py
```

**看到 "状态码: 200" 就成功了！**

## 🔍 如何识别节点地区？

节点名称中常见的关键字：

| 地区 | 关键字 | 推荐 |
|------|--------|------|
| 🇺🇸 美国 | US, USA, America, Los Angeles, San Francisco, New York | ✅ 强烈推荐 |
| 🇯🇵 日本 | JP, Japan, Tokyo, Osaka | ✅ 推荐 |

## ❌ 失败怎么办？

如果看到 `状态码: 400`：

**立即尝试：**
1. 切换到列表中的下一个美国/日本节点
2. 再次运行 `python test_api_endpoint.py`
3. 重复直到找到可用节点

**如果所有节点都是 400：**
- 您的代理服务可能没有美国/日本节点
- 考虑更换代理服务或使用 VPN

## 💡 小贴士

- **优先选美国节点**：成功率最高
- **选延迟低的**：< 300ms 为佳
- **多试几个**：不行就换下一个
- **记住可用节点**：找到后记下来，下次直接用
