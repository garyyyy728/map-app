# 豆包大模型 - 快速开始

## 📝 项目已切换到豆包大模型

项目已成功从 Google Gemini 切换到字节跳动豆包大模型！

## 🚀 快速开始

### 1. 获取 API Key

访问 [火山引擎控制台](https://console.volcengine.com/ark) 获取 API Key

### 2. 配置环境变量

参考 `env_example.txt` 创建 `.env` 文件：

```bash
DOUBAO_API_KEY=你的API密钥
DOUBAO_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 启动服务

```bash
python main.py
```

### 5. 访问文档

- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

## 📋 主要变更

### API 端点变更

所有 API 端点从 `/api/gemini/*` 改为 `/api/doubao/*`：

| 旧端点 | 新端点 | 说明 |
|--------|--------|------|
| `/api/gemini/generate` | `/api/doubao/generate` | 文本生成 |
| `/api/gemini/chat` | `/api/doubao/chat` | 对话接口 |
| `/api/gemini/analyze-image` | `/api/doubao/analyze-image` | 图片分析 |
| `/api/gemini/models` | `/api/doubao/models` | 模型列表 |

### 可用模型

- **doubao-1.5-pro-32k** - 主力模型（推荐用于日常对话）
- **doubao-1.5-pro-256k** - 长文本模型（支持超长上下文）
- **doubao-lite-32k** - 轻量模型（快速响应）
- **doubao-vision-pro-32k** - 视觉模型（图片分析专用）

### 配置文件变更

#### config.py
- `gemini_api_key` → `doubao_api_key`
- `api_title` 改为 "豆包 API 后台服务"
- 新增 `doubao_base_url` 配置

#### 依赖变更
- 移除：`google-genai`
- 新增：`openai>=1.0.0`（豆包使用 OpenAI 兼容接口）

## 💡 使用示例

### 文本生成

```python
import requests

response = requests.post(
    "http://localhost:8000/api/doubao/generate",
    json={
        "prompt": "请用简单的语言解释什么是人工智能",
        "model": "doubao-1.5-pro-32k",
        "temperature": 0.7,
        "max_tokens": 1000
    }
)
print(response.json())
```

### 多轮对话

```python
import requests

response = requests.post(
    "http://localhost:8000/api/doubao/chat",
    json={
        "messages": [
            {"role": "user", "content": "你好，请介绍一下自己"},
            {"role": "assistant", "content": "你好！我是基于豆包大模型的 AI 助手。"},
            {"role": "user", "content": "你能做什么？"}
        ],
        "temperature": 0.8
    }
)
print(response.json())
```

### 图片分析

```python
import requests

with open("image.jpg", "rb") as f:
    response = requests.post(
        "http://localhost:8000/api/doubao/analyze-image",
        files={"image": f},
        data={
            "prompt": "详细描述这张图片中的内容",
            "model": "doubao-vision-pro-32k"
        }
    )
print(response.json())
```

## 🔧 故障排查

### 问题：启动服务失败
**解决方法**：
1. 检查是否安装了所有依赖：`pip install -r requirements.txt`
2. 检查 `.env` 文件是否配置正确

### 问题：API 调用失败，提示认证错误
**解决方法**：
1. 检查 `DOUBAO_API_KEY` 是否正确
2. 确认 API Key 在火山引擎控制台是否启用

### 问题：图片分析失败
**解决方法**：
1. 确保使用 `doubao-vision-pro-32k` 模型
2. 检查图片格式是否支持（支持 JPEG、PNG）
3. 检查图片大小是否过大
