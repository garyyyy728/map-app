## 🚀 立即开始使用

```bash

```

```

```

## 💡 使用建议

1. **模型选择**
   - 日常对话：`doubao-1.5-pro-32k`
   - 长文本：`doubao-1.5-pro-256k`
   - 快速响应：`doubao-lite-32k`
   - 图片分析：`doubao-vision-pro-32k`

2. **性能优化**
   - 适当调整 `temperature` 参数（0.7-1.0）
   - 设置合理的 `max_tokens` 限制
   - 对于简单任务使用轻量模型

3. **成本控制**
   - 在火山引擎控制台设置费用预警
   - 监控 API 调用量
   - 根据需求选择合适的模型

## ⚠️ 注意事项

1. **API Key 安全**
   - ⚠️ 不要将 `.env` 文件提交到 Git
   - ⚠️ 不要在代码中硬编码 API Key
   - ✅ 使用环境变量管理敏感信息

2. **网络访问**
   - 确保可以访问 `ark.cn-beijing.volces.com`
   - 如需代理，在 `.env` 中配置
   - 国内网络通常可直接访问

3. **API 限制**
   - 注意调用频率限制
   - 单次请求大小限制
   - 并发请求数限制

## 🆘 遇到问题？

### 快速诊断

运行测试脚本：
```bash
python test_doubao.py
```

### 常见错误

**认证失败**
- 检查 `DOUBAO_API_KEY` 是否正确
- 确认 API Key 在控制台已启用

**网络错误**
- 检查网络连接
- 配置代理（如需要）
- 确认防火墙设置

**模型不存在**
- 使用推荐的模型名称
- 检查模型在你的账户中是否可用
