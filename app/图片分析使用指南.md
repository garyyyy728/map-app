### 方法 2: Python SDK（image_analyzer.py）

#### 基础示例

```python
from image_analyzer import ImageAnalyzer

# 创建分析器
analyzer = ImageAnalyzer()

# 基础分析
result = analyzer.analyze("photo.jpg", "描述这张图片")
print(result)
```

#### 完整功能演示

```python
from image_analyzer import ImageAnalyzer

analyzer = ImageAnalyzer()

# 1. 物体检测
objects = analyzer.detect_objects("street.jpg")
print("检测到的物体:", objects)

# 2. 场景描述
scene = analyzer.describe_scene("landscape.jpg")
print("场景描述:", scene)

# 3. OCR 文字提取
text = analyzer.extract_text("document.png")
print("提取的文字:", text)

# 4. 情感分析
emotion = analyzer.analyze_emotion("portrait.jpg")
print("情感分析:", emotion)

# 5. 颜色分析
colors = analyzer.identify_colors("painting.jpg")
print("颜色分析:", colors)

# 6. 构图分析
composition = analyzer.analyze_composition("photo.jpg")
print("构图分析:", composition)

# 7. 图片问答
answer = analyzer.answer_question(
    "chart.png", 
    "这个图表显示了什么趋势？"
)
print("回答:", answer)

# 8. 生成标题
caption = analyzer.generate_caption("photo.jpg", style="创意")
print("创意标题:", caption)

# 9. 质量评估
quality = analyzer.check_quality("photo.jpg")
print("质量评估:", quality)

# 10. 人脸检测
faces = analyzer.detect_faces("group_photo.jpg")
print("人脸检测:", faces)

# 11. 图片分类
category = analyzer.categorize("photo.jpg")
print("图片分类:", category)

# 12. 批量分析
images = ["img1.jpg", "img2.jpg", "img3.jpg"]
results = analyzer.batch_analyze(images, "描述这张图片")
for img_path, result in results.items():
    if result["success"]:
        print(f"{img_path}: {result['analysis']}")
    else:
        print(f"{img_path}: 失败 - {result['error']}")
```

#### 可用方法列表

| 方法 | 功能 | 示例 |
|------|------|------|
| `analyze()` | 基础分析 | `analyzer.analyze("img.jpg", "描述图片")` |

| `describe_scene()` | 场景描述 | `analyzer.describe_scene("img.jpg")` |
| `extract_text()` | OCR 文字提取 | `analyzer.extract_text("img.jpg")` |

| `identify_colors()` | 颜色识别 | `analyzer.identify_colors("img.jpg")` |
| `analyze_composition()` | 构图分析 | `analyzer.analyze_composition("img.jpg")` |
| `answer_question()` | 图片问答 | `analyzer.answer_question("img.jpg", "问题")` |
| `generate_caption()` | 生成标题 | `analyzer.generate_caption("img.jpg", "创意")` |
| `check_quality()` | 质量评估 | `analyzer.check_quality("img.jpg")` |
| `detect_faces()` | 人脸检测 | `analyzer.detect_faces("img.jpg")` |

## 💡 最佳实践

### 1. 提示词编写技巧

- ✅ **具体明确**：`"列出图片中所有可见的动物"` 而不是 `"看看这是什么"`
- ✅ **分步骤**：`"首先识别物体，然后描述它们的位置关系"`
- ✅ **指定格式**：`"用列表形式列出所有颜色"`
- ✅ **提供上下文**：`"这是一张产品图，请描述产品特征"`

### 2. 性能优化

```python
# 批量处理时使用 batch_analyze
images = ["img1.jpg", "img2.jpg", "img3.jpg"]
results = analyzer.batch_analyze(images)

# 而不是
for img in images:
    result = analyzer.analyze(img)  # 较慢
```

### 3. 错误处理

```python
try:
    result = analyzer.analyze("image.jpg")
    print(result)
except FileNotFoundError:
    print("文件不存在")
except Exception as e:
    print(f"分析失败: {e}")
```
