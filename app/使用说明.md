## 🔧 立即配置代理

### 步骤 1: 安装并启动代理工具

推荐使用（选择其中一个）：
- **Clash for Windows** (最推荐)
- V2rayN
- Shadowsocks

### 步骤 2: 查看代理端口

启动代理工具后，查看 HTTP 端口号，常见端口：
- Clash: `7890`
- V2rayN: `10809`
- Shadowsocks: `1080`

### 步骤 3: 配置 .env 文件

在项目根目录的 `.env` 文件中添加代理配置：

```env
# 已有的配置
GEMINI_API_KEY=AIzaSyAebsKqvJPLrt8FXZrYnRw28oLviH0jEtw
HOST=0.0.0.0
PORT=8000
DEBUG=True

# 添加代理配置（根据您的代理工具端口修改）
HTTP_PROXY=http://127.0.0.1:7890
HTTPS_PROXY=http://127.0.0.1:7890
```

### 步骤 4: 重启服务

停止当前服务（Ctrl+C），然后重新启动：

```bash
python main.py
```

### 步骤 5: 测试

```bash
python test_api.py
```

如果看到成功的响应，恭喜！🎉

## 💡 快速测试

### 测试文本生成（使用 PowerShell）

```powershell
$body = @{
    prompt = "用中文写一首关于秋天的诗"
    temperature = 0.8
} | ConvertTo-Json

Invoke-WebRequest `
    -Uri "http://localhost:8000/api/gemini/generate" `
    -Method POST `
    -Body $body `
    -ContentType "application/json"
```

### 测试对话（使用 Python）

```python
import requests

url = "http://localhost:8000/api/gemini/chat"
payload = {
    "messages": [
        {"role": "user", "content": "你好，请介绍一下自己"}
    ],
    "temperature": 0.7
}

response = requests.post(url, json=payload)
print(response.json()["reply"])
```
