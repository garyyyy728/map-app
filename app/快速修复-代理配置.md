# 🚨 快速修复：地理位置限制问题

## ❌ 问题

您看到的错误：
```
400 FAILED_PRECONDITION
User location is not supported for the API use.
```

**原因**：Gemini API 在中国大陆地区不可用，需要通过代理访问。

---

## ✅ 解决方案（5分钟搞定）

### 步骤 1：启动代理工具

确保您的代理工具正在运行：
- **Clash**: 确保正在运行，查看端口号（通常是 7890）
- **V2rayN**: 确保正在运行，查看 HTTP 端口
- **其他代理**: 确保 HTTP 代理可用

**如何查看端口号？**
- Clash: 设置 → 端口设置 → 端口号（默认 7890）
- V2rayN: 参数设置 → 本地监听端口

---

### 步骤 2：配置 .env 文件

1. 打开项目根目录的 `.env` 文件（如果没有，创建一个）

2. 添加以下内容（**修改端口号为您的代理端口**）：

```env
# Gemini API Key（保持不变）
GEMINI_API_KEY=你的API_KEY

# 代理配置（新增这两行）
HTTP_PROXY=http://127.0.0.1:7890
HTTPS_PROXY=http://127.0.0.1:7890
```

**⚠️ 重要**：
- 如果您的代理端口不是 7890，请修改为实际端口
- 常见端口：7890（Clash）、10809（V2rayN）、1080（Shadowsocks）

---

### 步骤 3：重启后端服务

1. **停止当前服务**（在运行 main.py 的终端按 `Ctrl+C`）

2. **重新启动服务**：
```bash
python main.py
```

3. **等待看到**：
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

---

### 步骤 4：测试

#### 方法 1：使用诊断脚本
```bash
python test_image_api.py
```

应该看到：
```
✅ 分析成功!
```

#### 方法 2：使用网页界面
1. 刷新 `web_image_upload.html`
2. 上传一张图片
3. 点击"开始分析"
4. 应该能看到分析结果

## 💡 常见问题

### Q1: 我不知道代理端口是多少？

**Clash 用户**:
1. 打开 Clash
2. 设置 → 端口设置
3. 查看"端口"（默认 7890）

**V2rayN 用户**:
1. 打开 V2rayN
2. 参数设置
3. 查看"本地监听端口"（默认 10809）

**Shadowsocks 用户**:
- 通常是 1080

### Q2: 还是不行？

1. **检查代理是否真的在工作**:
   - 在浏览器中访问 google.com
   - 如果能访问，代理工作正常

2. **检查 .env 文件格式**:
   ```env
   HTTP_PROXY=http://127.0.0.1:7890
   HTTPS_PROXY=http://127.0.0.1:7890
   ```
   - 注意：`http://`开头
   - 端口号正确
   - 没有多余的空格

3. **尝试不同的代理端口**:
   ```env
   # 尝试 7890
   HTTP_PROXY=http://127.0.0.1:7890
   
   # 或者 10809
   HTTP_PROXY=http://127.0.0.1:10809
   
   # 或者 1080
   HTTP_PROXY=http://127.0.0.1:1080
   ```

### Q3: 我的代理用的是 SOCKS5？

如果您的代理是 SOCKS5（比如端口 1080），需要转换为 HTTP 代理：

**方案 1**: 使用 Privoxy 转换（推荐）
```bash
# 安装 Privoxy（一次性操作）
# Windows: 下载安装 http://www.privoxy.org/

# 配置 Privoxy 监听 8118 端口，转发到 SOCKS5 1080

# 然后在 .env 中使用
HTTP_PROXY=http://127.0.0.1:8118
HTTPS_PROXY=http://127.0.0.1:8118
```

**方案 2**: 直接使用代理工具的 HTTP 端口
- 大多数代理工具同时提供 HTTP 和 SOCKS5 端口
- 使用 HTTP 端口即可
