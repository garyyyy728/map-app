## 🎯 ImageAnalyzer 提供的 13 种分析方法

| 序号 | 方法名 | 功能 | 应用场景 |
|------|--------|------|---------|
| 1 | `analyze()` | 基础分析 | 通用图片描述 |
| 2 | `detect_objects()` | 物体检测 | 识别图片中的所有物体 |
| 3 | `describe_scene()` | 场景描述 | 详细描述场景氛围 |
| 4 | `extract_text()` | OCR文字提取 | 发票、文档识别 |
| 5 | `analyze_emotion()` | 情感分析 | 识别人物表情情绪 |
| 6 | `identify_colors()` | 颜色识别 | 分析主色调配色 |
| 7 | `analyze_composition()` | 构图分析 | 评估摄影构图 |
| 8 | `answer_question()` | 图片问答 | 回答关于图片的问题 |
| 9 | `generate_caption()` | 生成标题 | 4种风格标题生成 |
| 10 | `check_quality()` | 质量评估 | 评估图片质量 |
| 11 | `detect_faces()` | 人脸检测 | 检测人脸及特征 |
| 12 | `categorize()` | 图片分类 | 自动分类图片 |
| 13 | `batch_analyze()` | 批量分析 | 高效处理多张图片 |

## 📈 性能优化建议

### 1. 批量处理
使用 `batch_analyze()` 而不是循环调用 `analyze()`

```python
# ❌ 较慢
for img in images:
    result = analyzer.analyze(img)

# ✅ 更快
results = analyzer.batch_analyze(images)
```

### 2. 调整超时
对于大图片，增加超时时间

```python
result = analyzer.analyze("large_image.jpg", timeout=120)
```

### 3. 优化提示词
使用具体明确的提示词

```python
# ❌ 模糊
analyzer.analyze("img.jpg", "看看这是什么")

# ✅ 明确
analyzer.analyze("img.jpg", "列出图片中的所有物体，用列表形式")
```
